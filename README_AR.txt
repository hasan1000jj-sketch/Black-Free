X Black - نسخة Python لأندرويد

الوظائف:
- واجهة عربية لإدخال اسم حساب تيك توك.
- اختيار نوع المخالفة وتدوين وصف الأدلة.
- حفظ سجلات البلاغات محلياً داخل بيانات التطبيق بصيغة JSON.
- فتح صفحة الحساب في تيك توك للوصول إلى الإبلاغ الرسمي يدوياً.

التشغيل على أندرويد:
1) ثبّت Pydroid 3 من متجر موثوق.
2) افتح Pydroid وثبّت مكتبة Kivy من قسم Pip (قد تحتاج إضافة/مستودع Kivy المتوافق مع إصدار Pydroid).
3) افتح main.py وشغّله.

لإنشاء APK مستقل:
يلزم عادةً Linux أو WSL مع Buildozer؛ لا يمكن إنتاج APK موثوق من ملف Python وحده على الهاتف. استخدم Buildozer بعد اختبار التطبيق.

مهم: التطبيق لا يرسل بلاغات آلية أو جماعية، ولا يستخدم واجهات خاصة أو يتجاوز حماية تيك توك. يحتفظ بسجل محلي ويساعدك على تقديم بلاغ صحيح يدوياً.
